How Qubere addresses it

Evidence, not prose. Same permissions, same audit log.

  • Every extracted fact carries its page number and bounding box, chained all the way back to the SHA-256-verified original.
  • Parser confidence, OCR confidence, model confidence, and validation status are four separate things — "not measured" is never shown as zero.
  • The assistant is a client of the existing app layer — its "value at risk" is the same computation the dashboard runs.
  • Write actions are permission-gated, audit-logged as assistant-initiated, and behind a confirmation step the button UI doesn't even have.
  • Origin safety: the model must quote the legal origin position verbatim — it may not substitute a manufacturer country.

Durable processing & quality gate

Upload is instant. Parsing survives a restart.

The upload request validates, stores the immutable original, hashes it, creates one durable run, and returns. A parse becomes the active version only if it passes an objective gate — text coverage, blank-page counts, parser warnings. No invented score.

  • Insufficient text → automatic OCR escalation → then a person
  • Reprocess creates a new version; the old one is kept for audit
  • Inbound email: forward documents to a per-tenant mailbox

Guardrails & write actions

Origin safety

It will not substitute a manufacturer country for an origin it doesn't have.

A dedicated tool surfaces a product's legal country-of-origin position. The system prompt forces the model to quote it verbatim and forbids falling back to a manufacturing, supplier, ship-from, or export country — even when the tool's own physical-fact fields mention one.

  • Retrieved document content enters the context in a labelled envelope — never an instruction
  • The model never sees SQL, an internal API, the page DOM, or an account id

Objection handling

Every hard question, answered directly.

"Which model? Are you sending our data to OpenAI?"Reasoning is Gemini (3.6 Flash default); Claude is wired as an alternative for the assistant and a few advisory routes. Parsing is IBM Docling. Model choice is per-surface config, and provenance records which model actually ran. No OpenAI.
"What if the AI is down?"Every workflow is fully usable without it. With no model key, the assistant route says so rather than answering from nothing; agent calls fail closed rather than fabricating.
"Can it read our whole database?"No. It calls a fixed tool registry, each running with the caller's real session context. The model never sees SQL, an internal API, the DOM, or a tenant id.
