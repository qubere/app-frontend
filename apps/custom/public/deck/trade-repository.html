"I know we have the manufacturer's origin declaration somewhere — I just don't know which of forty shipments it's attached to."

No cross-entity search

"We built a separate document widget for parties, another for products, another for filings — and now they all behave slightly differently."

Duplicated document UI

How Qubere addresses it

One link table. One component. One search page.

  • Any document can be linked to a shipment, party, product, license, or filing — not just the shipment it happened to arrive on.
  • Unlinking is never a delete — the link is marked inactive and the history stays, so nothing about "this used to be evidence for X" is lost.
  • Every entity detail page renders the same linked-documents panel, backed by the same API — no bespoke document UI per module.
  • Trade Repository searches every document in the account by name, type, status, or which entity it's linked to — independent of any one shipment page.
  • A link can never be created against another tenant's record, or a record that doesn't exist — the target is verified before the link is written.

One link table · shared document panel

A document isn't owned by one record — it's linked to as many as apply.

A document-to-entity link records which entity, what kind of relationship (source document, supporting document, filing attachment, license evidence, origin evidence), who created it and when. The same panel renders on the party, product, and filing detail pages, and on the shipment workspace — one component, one API, no drift between them.

  • Unlink sets the link inactive and stamps who/when — the link history is never deleted
  • Pre-existing shipment-attached documents were migrated into this model, not left behind

Objection handling

Every hard question, answered directly.

"Can a document belong to more than one shipment?"Yes — and to a party, product, license, or filing at the same time. That's the point of the link layer: the document is the file; the links are the facts about what it's evidence for.
"If we unlink something by mistake, is it gone?"No. Unlinking marks the link inactive and records who did it and when; it never deletes the row. The history of "this was once evidence for X" survives.
"Does License get the same linked-documents panel?"Not yet — License has its own, older document mechanism, and wiring it into this shared panel is deliberately deferred pending a product decision on how the two should coexist.
